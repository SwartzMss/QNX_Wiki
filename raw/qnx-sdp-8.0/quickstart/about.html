These guidelines will help you install the QNX Software Development Platform, quickly develop a program, and run it on a QNX OS target.

For developing software on Linux and Windows, you can use the command line. Alternatively, you can use the QNX Momentics IDE (Integrated Development Environment) or QNX Toolkit for VS Code.
