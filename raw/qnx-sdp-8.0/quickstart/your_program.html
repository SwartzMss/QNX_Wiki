Using the command line to develop your program

QNX SDP8.0Quickstart GuideDeveloperSetup

Typical command-line steps to developing a program on the QNX SDP platform are as follows:

  1. Run a script to set the environment variables for your command-line window. The script can be found wherever you installed your QNX SDP, called base_directory in the examples below.

    On Windows, run:

    base_directory\qnxsdp-env.bat

    On Linux, run:

    source base_directory/qnxsdp-env.sh
  2. Set up the virtual machine (VM).
    1. Download and install VM software; for example, VMware.
      Note:
      This step is required before running virtual guests. See the target system options in the Installation chapter.
    2. Create a folder for the VM and change directory as follows: 
      mkdir qnx-vm
cd qnx-vm
    3. Generate a VM image using mkqnximage: 
      mkqnximage --type=vmware
    4. Start the VM: 
      mkqnximage --run
    5. Retrieve the VM target's IP: 
      mkqnximage --getip
    6. Verify connectivity using the IP retrieved; for example: 
      ping 192.168.91.128
  3. Create a folder for your project and change directory as follows: 
    mkdir hello-qnx
cd hello-qnx
  4. Create a "Hello QNX!" program in your favorite editor; for example: 
    #include <stdio.h>
                
int main() {
            printf("Hello QNX!\n");
            return 0;
            }
  5. Compile your program using qcc: 
    qcc -o hello hello.c
  6. Transfer your compiled program to a target: 
    scp hello root@192.168.91.128:/tmp
  7. Run your program from the VM terminal, or open a remote SSH terminal and run from /tmp:
    cd /tmp; ./hello
    If the command runs correctly, this expected output is displayed: 
    Hello QNX!

For more details on using command-line tools for writing and compiling a program, go to the Compiling and Debugging chapter of the QNX OS Programmer's Guide.
