# 版本范围

> 适用版本：QNX SDP 8.0 · 更新：2026-11-27

本 Wiki 的首轮主题只依据 QNX SDP 8.0 文档。仓库 `raw/` 保存的文件和抓取日期见[资料清单](../raw/README.md)，逐文件官方地址和 SHA-256 见[清单](../raw/manifest.tsv)。QNX 的 [8.0 文档集](https://www.qnx.com/developers/docs/8.0/com.qnx.doc.qnxsdp.nav/topic/bookset.html)把系统架构、编程、组件操作和 API 参考分开组织。

[QNX SDP 8.0.6 Release Notes](https://www.qnx.com/developers/docs/relnotes8.0/com.qnx.doc.release_notes/topic/8.0.6_prod_release_notes/8.0.6_rn.html)也已归档，但本轮没有逐项审阅其修复与已知问题。因此，主题页的“SDP 8.0”表示所引用文档所属的产品线，**不表示已经验证每个 8.0.x 补丁版本的行为相同**。涉及具体补丁、硬件或已知缺陷时，应先查相应 release notes。

7.1 及更早版本目前不在 Wiki 的结论范围内；跨版本问题应分别查对应官方文档和[迁移到 QNX OS 8.0 的指南](https://www.qnx.com/developers/docs/8.0/com.qnx.doc.qnxsdp.migration/topic/about.html)。

本页链接的 8.0 文档集目录和迁移指南是官网在线导航入口，尚未保存在 `raw/`；本轮主题页的具体技术依据均来自已归档页面。
